# Persona · Ventas de la saga

Presentación interactiva (estilo Persona 3) del análisis de ventas de la saga Persona.

- `index.html`: página única, lista para Netlify (sin build; directorio de publicación: raíz).
- Controles: flechas o WASD para navegar, Enter para entrar, Esc para volver, P para letra grande, E para explicaciones.
- Música: playlist de Persona 3 Reload vía reproductor oficial de YouTube.
